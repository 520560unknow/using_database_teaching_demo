# 视频播放与弹幕系统修改方案

## 一、当前系统分析

### 现有组件
- **Danmaku.java**: 弹幕模型，适用于课堂环境
- **DanmakuService.java**: 弹幕服务，提供基础的弹幕管理功能
- **WebSocketConfig.java**: WebSocket配置
- **StudentWebSocketHandler.java**: 学生WebSocket处理器
- **TeacherWebSocketHandler.java**: 教师WebSocket处理器

### 现有问题
1. **缺少视频模型**：没有专门的视频实体类
2. **缺少视频控制器**：没有处理视频相关HTTP请求的控制器
3. **弹幕系统简单**：缺少视频特定的弹幕功能
4. **缺少播放统计**：没有视频播放量统计机制
5. **WebSocket功能有限**：主要针对课堂互动，缺少视频弹幕的实时处理

```java
package com.example.classroom.service;

import com.example.classroom.model.Video;
import org.springframework.stereotype.Service;

import java.util.ArrayList;
import java.util.Date;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

@Service
public class VideoService {
    private Map<Integer, Video> videoMap = new ConcurrentHashMap<>();
    private int nextId = 1;

    public Video addVideo(Video video) {
        if (video.getId() == null) {
            video.setId(nextId++);
        }
        video.setCreateTime(new Date());
        video.setUpdateTime(new Date());
        video.setViews(0);
        video.setLikes(0);
        video.setFavorites(0);
        video.setComments(0);
        videoMap.put(video.getId(), video);
        return video;
    }

    public Video getVideoById(int id) {
        return videoMap.get(id);
    }

    public List<Video> getAllVideos() {
        return new ArrayList<>(videoMap.values());
    }

    public void updateVideoViews(int vid, boolean isUser) {
        Video video = videoMap.get(vid);
        if (video != null) {
            video.setViews(video.getViews() + 1);
            video.setUpdateTime(new Date());
        }
    }

    public void updateVideoLikes(int vid, int delta) {
        Video video = videoMap.get(vid);
        if (video != null) {
            video.setLikes(Math.max(0, video.getLikes() + delta));
            video.setUpdateTime(new Date());
        }
    }

    public void updateVideoFavorites(int vid, int delta) {
        Video video = videoMap.get(vid);
        if (video != null) {
            video.setFavorites(Math.max(0, video.getFavorites() + delta));
            video.setUpdateTime(new Date());
        }
    }
}
```

```java
package com.example.classroom.service;

import com.example.classroom.model.Danmaku;
import org.springframework.stereotype.Service;

import java.util.ArrayList;
import java.util.Date;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

@Service
public class DanmakuService {
    private Map<Integer, List<Danmaku>> videoDanmakuMap = new ConcurrentHashMap<>();
    private int nextId = 1;

    public Danmaku addDanmaku(Danmaku danmaku) {
        if (danmaku.getId() == null) {
            danmaku.setId(nextId++);
        }
        danmaku.setCreateDate(new Date());
        danmaku.setState(1); // 默认为正常状态

        List<Danmaku> danmakuList = videoDanmakuMap.computeIfAbsent(danmaku.getVid(), k -> new ArrayList<>());
        danmakuList.add(danmaku);

        return danmaku;
    }

    public List<Danmaku> getDanmakuByVideoId(int vid) {
        return videoDanmakuMap.getOrDefault(vid, new ArrayList<>());
    }

    public List<Danmaku> getDanmakuByTimeRange(int vid, double startTime, double endTime) {
        List<Danmaku> allDanmaku = videoDanmakuMap.getOrDefault(vid, new ArrayList<>());
        List<Danmaku> result = new ArrayList<>();
        
        for (Danmaku danmaku : allDanmaku) {
            if (danmaku.getTimePoint() >= startTime && danmaku.getTimePoint() <= endTime) {
                result.add(danmaku);
            }
        }
        return result;
    }

    public void deleteDanmaku(int id) {
        for (List<Danmaku> danmakuList : videoDanmakuMap.values()) {
            danmakuList.removeIf(d -> d.getId().equals(id));
        }
    }
}
```

#### 1.4 WebSocket层

**创建 `DanmuWebSocketServer.java`**
```java
package com.example.websocket;

import com.example.classroom.model.Danmaku;
import com.example.classroom.service.DanmakuService;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;
import org.springframework.web.socket.CloseStatus;
import org.springframework.web.socket.TextMessage;
import org.springframework.web.socket.WebSocketSession;
import org.springframework.web.socket.handler.TextWebSocketHandler;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

@Component
public class DanmuWebSocketServer extends TextWebSocketHandler {

    @Autowired
    private DanmakuService danmakuService;

    @Autowired
    private ObjectMapper objectMapper;

    private Map<Integer, Map<String, WebSocketSession>> videoSessions = new ConcurrentHashMap<>();

    @Override
    public void afterConnectionEstablished(WebSocketSession session) throws Exception {
        String uri = session.getUri().toString();
        int vid = extractVideoId(uri);
        
        if (vid > 0) {
            Map<String, WebSocketSession> sessions = videoSessions.computeIfAbsent(vid, k -> new ConcurrentHashMap<>());
            sessions.put(session.getId(), session);
        }
    }

    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) throws Exception {
        String payload = message.getPayload();
        Map<String, Object> data = objectMapper.readValue(payload, Map.class);
        
        // 解析弹幕数据
        Danmaku danmaku = new Danmaku();
        danmaku.setVid((Integer) data.get("vid"));
        danmaku.setUid((Integer) data.get("uid"));
        danmaku.setContent((String) data.get("content"));
        danmaku.setFontsize((Integer) data.getOrDefault("fontsize", 25));
        danmaku.setMode((Integer) data.getOrDefault("mode", 1));
        danmaku.setColor((String) data.getOrDefault("color", "#FFFFFF"));
        danmaku.setTimePoint((Double) data.get("timePoint"));

        // 保存弹幕
        Danmaku savedDanmaku = danmakuService.addDanmaku(danmaku);

        // 广播给所有观看同一视频的用户
        broadcastDanmaku(savedDanmaku.getVid(), savedDanmaku);
    }

    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) throws Exception {
        String uri = session.getUri().toString();
        int vid = extractVideoId(uri);
        
        if (vid > 0) {
            Map<String, WebSocketSession> sessions = videoSessions.get(vid);
            if (sessions != null) {
                sessions.remove(session.getId());
                if (sessions.isEmpty()) {
                    videoSessions.remove(vid);
                }
            }
        }
    }

    private void broadcastDanmaku(int vid, Danmaku danmaku) throws Exception {
        Map<String, WebSocketSession> sessions = videoSessions.get(vid);
        if (sessions != null) {
            String danmakuJson = objectMapper.writeValueAsString(danmaku);
            TextMessage message = new TextMessage(danmakuJson);
            
            for (WebSocketSession session : sessions.values()) {
                if (session.isOpen()) {
                    session.sendMessage(message);
                }
            }
        }
    }

    private int extractVideoId(String uri) {
        // 从URI中提取视频ID
        // 示例: /ws/danmu/123 -> 123
        try {
            String[] parts = uri.split("/");
            return Integer.parseInt(parts[parts.length - 1]);
        } catch (Exception e) {
            return 0;
        }
    }
}
```

```java
package com.example.websocket;

import com.example.websocket.StudentWebSocketHandler;
import com.example.websocket.TeacherWebSocketHandler;

import org.springframework.web.socket.config.annotation.EnableWebSocket;

import org.springframework.web.socket.config.annotation.WebSocketHandlerRegistry;
import org.springframework.beans.factory.annotation.Autowired;

@Configuration
@EnableWebSocket
public class WebSocketConfig implements WebSocketConfigurer {

    @Autowired
    private StudentWebSocketHandler studentWebSocketHandler;

    @Autowired
    private TeacherWebSocketHandler teacherWebSocketHandler;

    @Autowired
    private DanmuWebSocketServer danmuWebSocketServer;

    @Override
    public void registerWebSocketHandlers(WebSocketHandlerRegistry registry) {
        // 学生 WebSocket 端点
        registry.addHandler(studentWebSocketHandler, "/ws/student/{classroomId}")

        // 教师 WebSocket 端点
        registry.addHandler(teacherWebSocketHandler, "/ws/teacher/{classroomId}")
                .setAllowedOriginPatterns("*");

        // 弹幕 WebSocket 端点
        registry.addHandler(danmuWebSocketServer, "/ws/danmu/{vid}")
                .setAllowedOriginPatterns("*");
    }
}
```

## 三、优缺点分析

### 优点

1. **功能完整**：实现了视频播放、弹幕、播放统计等完整功能
2. **实时性好**：通过WebSocket实现了实时弹幕通信
3. **用户体验佳**：支持多种弹幕模式和颜色，增强互动性
4. **架构清晰**：遵循MVC架构，代码结构合理
5. **可扩展性强**：模块化设计，便于后续功能扩展
6. **兼容性好**：支持登录用户和游客的不同播放统计机制

### 缺点

1. **性能问题**：
   - 大量弹幕同时发送时可能导致服务器压力增大
   - WebSocket连接数过多时可能影响系统稳定性

2. **安全性问题**：
   - 缺少弹幕内容审核机制，可能出现不良内容
   - WebSocket连接缺少严格的身份验证

3. **用户体验问题**：
   - 弹幕密度过大时可能影响视频观看
   - 缺少弹幕开关和透明度调节功能

4. **存储问题**：
   - 使用内存存储视频和弹幕数据，重启后数据丢失
   - 缺少持久化存储机制

5. **扩展性问题**：
   - 缺少视频分类和搜索功能
   - 缺少用户个人中心和历史记录功能

## 四、改进建议

### 1. 性能优化
- **使用Redis**：存储热点数据和WebSocket会话信息
- **消息队列**：使用Kafka处理高并发弹幕消息
- **负载均衡**：部署多个WebSocket服务器实例
- **限流措施**：限制单个用户的弹幕发送频率

### 2. 安全性改进
- **弹幕审核**：实现AI自动审核和人工审核机制
- **身份验证**：使用JWT token验证WebSocket连接
- **内容过滤**：过滤敏感词和不良内容
- **防刷机制**：加强播放量和弹幕的防刷措施

### 3. 用户体验优化
- **弹幕控制**：添加弹幕开关、透明度调节、密度控制
- **弹幕样式**：支持更多弹幕样式和动画效果
- **移动端适配**：优化移动端弹幕显示效果
- **互动增强**：添加弹幕点赞、回复功能

### 4. 存储改进
- **数据库存储**：使用MySQL存储视频和弹幕数据
- **文件存储**：使用OSS存储视频文件
- **缓存策略**：实现多级缓存策略，提高访问速度
- **数据备份**：定期备份视频和弹幕数据
